部署与数据

本站是一个静态站点，打开即用，不需要安装任何依赖。 下面只说明「数据存在哪里」和「怎么备份」。

一、数据存在哪里

内容存在哪换设备还能看到吗
账号、消息、房间服务器能
贴吧帖子服务器能
图片、视频、语音本机，上传后同步到服务器通常能
服务器连不上时会退回本机模式，页面顶部会明确提示。 此时新发的内容只存在这台设备的浏览器里，等恢复后不再可见于其他设备。
重要：重新上传代码或回滚版本，清不掉各人浏览器里的数据。 数据按域名存储，不按路径，所以把聊天室从 /Chat/ 搬到 /Chat/chat/ 不会丢数据。要清空只能本人清浏览器站点数据，或站长用「管理面板 → 站点 → 重置站点」。

二、跨设备搬运聊天数据

管理面板 → 站点 → 导出 JSON，在另一台设备上 导入 JSON。 导入走的是与同步完全相同的合并逻辑（按 id 去重、按时间取新、删除不可逆）， 本地与上线版操作一致。

三、本地运行

# 方式 1：直接双击（最快，但部分浏览器会限制 IndexedDB 与录音）
双击 chat/index.html

# 方式 2：起本地服务（推荐，功能完整）
python3 chat/server.py --port 8000
# 浏览器打开 http://localhost:8000/

server.py 只用 Python 标准库，只是把静态文件以 http 方式送出去， 不存数据、不做同步。

四、浏览器要求

Chrome / Edge / Firefox / Safari 近两年版本均可。 file:// 直接打开时部分浏览器会限制 IndexedDB 与录音， 此时媒体存内存、WASM 自动跳过，聊天功能照常。
