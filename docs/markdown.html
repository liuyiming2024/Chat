Markdown 与公式

输入框里直接写 Markdown 语法，发送后自动渲染。公式用 $ 包裹—— 行内一个 $，块级两个 $$。

一、Markdown 语法

代码块示例

```cpp
#include <iostream>
int main() {
    std::cout << "Hello" << std::endl;
    return 0;
}
```

代码块会按语言着色（C++ / Python / JavaScript 等），右上角有「复制」按钮。

专业模式下工具条上有个「√」按钮，点开是公式符号面板， 点一下就把符号插到光标处，不用手敲反斜杠。 写 $ 或 $$ 也可以用工具条按钮自动生成包裹。

三、极简模式的区别

极简模式下语法工具条和「?」帮助按钮会隐藏，界面更干净， 但公式照常渲染——只是不显示那些辅助入口而已。 你照常写 $...$ 就行。

四、转义

如果某段文字里出现了会被误判的符号（比如想原样显示 $5 和 $10）， 可以在 $ 前加反斜杠：\$5 和 \$10。
