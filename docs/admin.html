管理员手册

一、审核注册申请

管理面板 → 审核 页签。每条申请显示昵称、申请说明、申请时间， 右边一个 ✓ 一个 ✗，点一下就完成，不用进弹窗。

  • 通过：对方即可用注册时填的密码登录，全场会收到一条系统消息。
  • 拒绝：可填拒绝理由。选「删除申请」对方能用同一昵称重新提交； 选「保留为已拒绝」则不再出现在待审核列表里。对方下次登录会看到你填的理由。

这里不是实名制，不强制填真实姓名。唯一的把关材料就是申请人自己写的那段说明。

二、消息四档处置（别搞混）

动作谁可以做范围内容释放空间
删除任何人仅本账号隐藏保留（别人照常看到）否
撤回作者本人，5 分钟内全站前台隐藏保留，后台可查否
移除管理员 / 站长全站前台隐藏保留，后台可查否
Delete仅站长物理抹除销毁是
撤回和移除都刻意保留原文——前台显示"已撤回"或"已被管理员移除"， 但管理员可以点气泡上的「查看原文」追溯内容，操作日志里也有摘要。 只有 Delete 是真正的物理删除，会连同图片视频一起释放空间，不可恢复。

三、准入方式三选一

方式设置适合
申请 + 审核开放注册 开 · 注册审核 开想认识的人自己申请，你把关
免审核开放注册 开 · 注册审核 关完全开放，填完即用
仅手动开户开放注册 关最严格，只能你「用户 → ＋手动开户」

设置位置：管理面板 → 站点 页签。手动开户时你填昵称和初始密码，对方直接可登录。

四、清理旧媒体（有安全锁）

管理面板 → 站点 → 清理旧媒体。流程强制两步：

  1. 先点「第一步：导出 JSON 备份」下载备份文件；
  2. 没备份就点「确认清理」会被拦下并提示；备份完成后才允许清理。

清理只删图片视频等媒体，消息文字本身保留并标注"媒体已清理"。可选 7 / 30 / 90 天前。

五、其他管理操作

操作位置

导出聊天记录（md / txt）站点 → 导出聊天记录
查看存储用量站点 → 存储用量
日志筛选（按人 / 类型 / 关键词）管理面板 → 日志
恢复自己删掉的消息站点 → 恢复已删除
重置站点站点 → 重置站点

六、备份提醒

管理员登录后，若距上次备份超过 7 天会收到提示。 导出 JSON 后会自动记录备份时间。建议定期导出一份留底—— 聊天数据只存在各人浏览器里，清了浏览器就没了。
