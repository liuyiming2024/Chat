# 原生端真机验证清单

> 单元测试（CI 里几秒出结果）只能验**规则**，
> 验不了**真机行为**——通知、相册、存储、断网补发这些都只能在设备上确认。
> 这份清单是给"第一次拿到 APK 装到手机上"的时候逐条走的。

## 0. 装前

- [ ] 从 Actions 下载 `chat-native-debug` 产物（`build-native.yml`）
- [ ] 记下手机 Android 版本（需 ≥ 8.0 / API 26）
- [ ] **先卸载旧包再装**：versionCode 从 1 起，与 Web 版壳子不冲突，但同包名残留数据会混淆判断

## 1. 登录

- [ ] 打开 → 出现登录页（不是白屏）
- [ ] 输入 `liuyiming2024` / `20120421lym` → 进入会话列表
- [ ] 输错密码 → 提示"登录失败"，**输入的内容还在**（被清空的话重新输一遍很折磨）
- [ ] 杀进程重开 → **仍保持登录**（令牌落了 Room，不是只在内存里）

## 2. 消息

- [ ] 进入「公屏大厅」→ 能看到服务端已有的验证消息
- [ ] 发一条普通文字 → 出现在列表里
- [ ] 发 `**粗体**` → **渲染成粗体**，不是原样露出一堆星号（NATIVE-MD）
- [ ] 发 `` `代码` `` → 等宽样式
- [ ] 发一段纯文字（不含 `**`、`` ` ``、`# `、`](`）→ 正常（走的是跳过渲染的快路径）
- [ ] 深色模式下切到含 Markdown 的消息 → **文字看得见**（主题色没传会与背景同色）
- [ ] 粘贴 8001 字 → **点发送之前**就提示超长，且输入框内容还在（S-101）
- [ ] 发一条 → 撤回 → 消失
- [ ] 等 6 分钟后再点那条 → 按钮**不消失**，标"已超时"（凭空消失会以为坏了）

## 3. 断网补发（最容易出问题的一段）

- [ ] 飞行模式下发 3 条 → 顶部出现**待发条数**（不是静默）
- [ ] 提示文案说清"已存入待发队列，联网后自动补发"，不是只说"发送失败"
- [ ] 关飞行 → 点「立即重试」→ 3 条全部发出，**对方只收到 3 条不是 6 条**
- [ ] 补发完成后待发条数归零

## 4. 媒体

- [ ] 发一张图 → 能发出、能点开看
- [ ] **重启手机** → 图还在（落 `filesDir` 不是 `cacheDir`，cache 会被清）
- [ ] 设置里看媒体占用 → 有数字（不显示的话用户发现存储没了不知谁占的）
- [ ] 系统没弹"读取存储权限"请求（用的是系统照片选择器）

## 5. 通知

- [ ] Android 13+：首次进 App 会问通知权限
- [ ] **拒绝后不反复弹**（NATIVE-MSG：不弹设置页骚扰）
- [ ] 授予后收到新消息 → 状态栏有通知

## 6. 多语言

- [ ] 设置里切 English → 界面文案变英文（**立刻变**，不是下次启动才变）
- [ ] 切回中文 → 变回
- [ ] 界面上**没有出现英文 key**（如 `common.close`）——出现即为词典缺 key

## 7. 退出重进

- [ ] 杀进程 → 重开 → 语言设置还在（落了 SharedPreferences）
- [ ] 断网状态下打开 → 显示本地已缓存的消息，不是空白
