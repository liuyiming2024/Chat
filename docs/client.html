客户端下载

网页版打开即用，不用装任何东西。客户端是可选的—— 想要独立窗口、系统托盘、开机自启这类体验时才需要它。 两边的消息完全互通，装不装不影响你跟谁聊。

一、各平台怎么拿

平台文件大小怎么装
Windowschat-win-setup.exe76 MB 双击安装。SmartScreen 提示时点「仍要运行」
Windows 便携chat-win-portable.exe76 MB 双击即用，不安装、不写注册表
macOSchat-mac.dmg94 MB 拖进 Applications
Linuxchat-linux.AppImage103 MB 加执行权限后直接运行
安卓chat-android.apk3.2 MB 需允许「未知来源」安装
下载直链不用登录，格式是 releases/latest/download/文件名—— 写死的链接会自动指向最新版，不用手动找版本号。

二、第一次打开会被拦一下

这个文件没有做商业签名（正规证书要花钱，本项目零成本运行）， 所以各系统都会拦一次。拦是系统该做的，点过去就行：

系统你会看到怎么做
Windows蓝色「Windows 已保护你的电脑」点「更多信息」→「仍要运行」
macOS「无法打开，因为来自身份不明的开发者」 右键点应用 →「打开」，不要双击。只第一次需要
安卓「未知来源应用」设置里允许一次
macOS 那步容易踩：直接双击会一直弹同样的框，怎么点都打不开。 必须是右键→「打开」，弹框里才会多出「打开」按钮。

三、苹果手机没有独立 App

App Store 上架需要 Apple 开发者账号（每年 99 美元），不在本项目预算内。 但效果基本一样——用浏览器把它装到桌面：

  1. iPhone / iPad 用 Safari 打开本站
  2. 点底部「分享」按钮
  3. 选「添加到主屏幕」

之后桌面会出现独立图标，点开全屏运行、没有浏览器地址栏， 还能离线使用。不经过 App Store，不花一分钱。

四、自动更新

客户端启动时会自己查一次有没有新版，有了会提示。 几个细节值得知道：

  • 多个源自动测速。它对候选源各取一小段计时，选最快的下载， 中途失败了自动换下一个。你不用管从哪下。
  • 分块下载。大文件切成几片同时拉，某一片失败只重传那一片， 不用整个文件从头来。断网重连也能接着下。
  • 换源不用重新装。下载源写在一份在线清单里， 改了清单客户端自己就会用新的。
  • 下载完成后不会替你安装——它会打开文件夹让你自己装。 自动静默覆盖正在运行的应用不合适。

五、桌面版登录之后，网页版可以直接进

如果你在这台电脑上开着桌面版并已登录，打开网页版登录页时， 会多出一行提示「检测到这台电脑上已登录 XXX」，点一下就能直接进。

它只省掉账号密码，不省站点保护密码。 这是两道门：一道是你这个账号，一道是整站门禁。 桥接帮你过第一道，第二道该输还得输。

没出现这行提示也没关系——那是正常情况，不是坏了。 它只在「桌面版开着且已登录」时才出现， 没装客户端、或客户端没登录，都会安静地不显示。

六、没装也能用

网页版功能和客户端完全一致，消息互通。不装不会少任何功能。 客户端多的只是：独立窗口、系统托盘、开机自启、以及上面那个免密进入。
