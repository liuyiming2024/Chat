# 聊天室

三栏即时通讯布局 + LaTeX 公式的注册审核制网页聊天室：进入密码保护、
私聊 / 自建群 / 公屏大厅、图片视频预览、Markdown 与 `$...$` 公式。

在线地址：<https://liuyiming2024.github.io/Chat/>

---

## 快速开始

**双击 `index.html` 即可使用**，无需安装任何依赖。

如需完整功能（媒体持久化），起一个本地静态服务：

```bash
python3 server.py        # 然后打开 http://localhost:8000/
```

---

## 首次进入：三步初始化

1. **设保护密码** —— 进入站点的第一道门，之后每次从后台切回都要重新输入
2. **建站长账号** —— 第一个注册的账号自动成为站长
3. **邀请成员** —— 新账号需站长在管理面板审核通过后才能发言

新账号注册后处于待审核状态，可以登录但不能发言，审核通过后自动加入公屏。

---

## 功能一览

- **房间**：公屏大厅、私聊、自建群（可设密码、公告）
- **消息**：文本、图片、视频、语音、文件；Markdown 与 LaTeX 公式
- **快捷命令**：输入框以 `/` 开头，如 `/help` `/nick` `/clear`
- **管理**：三级管理员体系、权限矩阵、禁言、审核、封禁
- **主题**：极简 / 专业双模式，深色模式

完整说明见使用手册。

---

## 安全与隐私

- 密码一律加盐 + 多轮迭代后存储，任何模式下都不明文落盘
- 站点保护密码与登录密码相互独立
- 这是面向熟人小圈子的轻量实现，不是企业级安全产品，**不要用于敏感信息传输**

## 浏览器要求

Chrome / Edge / Firefox / Safari 近两年版本均可。
`file://` 直接打开时部分浏览器会限制 IndexedDB，此时媒体存内存，
聊天功能照常；用 `python3 server.py` 或在线版打开则全部功能可用。
