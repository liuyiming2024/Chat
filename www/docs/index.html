最快的上手路径

  1. 打开 聊天室，设保护密码 → 建站长账号 → 进入。
  2. 再开一个浏览器标签页（或换一个浏览器），注册第二个账号，就能自测私聊。
  3. 想写公式，看 Markdown 与公式。
  4. 要管人、管群，看 管理员手册。
自测技巧：同一浏览器开两个标签页，注册两个账号，即可实时私聊、建群、 体验管理员权限。这是同源广播的效果，本地与上线版都支持。
