权限与命令

一、权限三态

每项权限对每个人有三种状态：

状态含义优先级
继承按角色默认走（有管理员模板和成员模板）最低
允许单独授予，覆盖角色默认中
禁止单独收回，压过角色默认最高（站长除外）

判定顺序：封禁 → 站长恒为全部权限 → 显式禁止 → 显式允许 → 角色默认 → 群主/群管理员。

管理员只是称号。同样是管理员，各人手里实际能做什么可以完全不同—— 这正是由逐项勾选决定的。想给某人特殊权力，不必提拔他，直接勾那一项就行。

三、怎么设置

管理面板 → 权限 页签 → 点某人「分配权限」→ 逐项改成 继承 / 允许 / 禁止。

有三个快捷套用：

  • 管理员模板——一次性给全套常用管理权；
  • 普通成员模板——收回管理权，退回普通成员；
  • 全部恢复继承——清空自定义，全部按角色走。

页面底部有一张只读的「角色默认权限」对照表，说明"继承"到底继承的是什么。

站长不可剥夺。站长恒为全部权限，不参与勾选，界面上显示为「全部权限（不可剥夺）」。 想改只能先转让站长给别人，自己变成管理员后再由新站长调整。
