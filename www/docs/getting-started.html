新手入门

一、三步初始化

1

站点保护密码

所有人进入站点都要先输这道密码（≥4 位），输错进不去。它是"整站的门禁"，不等于你的登录密码。

2

站长账号

填昵称和登录密码（≥4 位），自动成为站长，拥有全部权限。

3

成员加入

成员在登录页点「注册」，写一段申请说明，等站长通过后即可登录。

二、发消息

  • 输入框打字，按 Enter 发送，Shift+Enter 换行。 这个行为可以在「管理面板 → 站点 → 发送键」里改。
  • 输入框上方的按钮：图片、视频、文件、语音、表情、@ 提及某人、? 语法帮助。
  • 也可以直接把图片或视频拖进窗口发送。
  • 点消息上的「引用」可以带原文回复。
  • 右上角 专业 / 极简 按钮切换模式：极简模式只留加号与表情，专业模式显示语法工具条。

三、会话：公屏、私聊、群

类型怎么进说明
公屏大厅默认就在所有人都能说话的大厅，可设公告
私聊点头像选「私聊」，或 /dm 昵称 内容一对一，自动建会话
自建群/create 群名，或侧栏「＋」可设群密码、公告、简介
加密群输入群密码加入群主可在群设置里设或取消密码

想让别人进你的群：群菜单里「生成邀请口令」，把 6 位口令发给对方， 对方在「用口令加入房间」里输入即可。

四、常用操作

想做什么怎么做
改昵称、头像、密码点头像 →「我的资料」
查看群成员右上角「成员」按钮
找历史消息消息搜索（管理面板入口或搜索按钮）
导出聊天记录管理面板 → 站点 → 导出聊天记录（md 或 txt）
切换深色模式右上角月亮图标按钮，或管理面板 → 站点 → 外观
把某条消息藏起来消息操作条 →「删除」
改已发出的消息消息操作条 →「编辑」，改完会显示「已编辑」
把重要消息钉在顶部消息操作条 →「置顶」（需权限）
某个会话不想被提醒群菜单 →「免打扰此会话」；也能按时段、按人设
翻更早的历史滚到消息区顶部会自动再加载一批；也可以点顶部「加载更早」
切换界面语言点头像 →「我的资料」→ 语言（跟随浏览器，也可手动改）

五、断网时发的消息会怎样

离线时你照样能发——消息先排在本机的队列里，界面上标着「待发送」。 联网后它会按原顺序一条条补发出去，你不用重发，也不用盯着。

补发时用的是服务器时间，不是你本机的时间。 本机时钟可能不准，用它会导致消息插在别人中间、顺序错乱。

六、想装客户端

网页版功能已完整，不装也能用。想要独立窗口、托盘图标、开机自启， 或者「桌面版已登录、网页端直接进」，就看 客户端下载。

七、语音消息的注意点

录音需要麦克风权限，且只在 https 或 localhost 下可用。 通过 GitHub Pages 访问没问题；但如果你把文件下载下来直接双击打开（file:// 协议）， 浏览器会拒绝录音，此时要用 python3 chat/server.py 起个本地服务再打开。
