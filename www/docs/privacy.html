隐私声明

本站是个人自部署的聊天站点，不是商业服务。 下面说清楚：你的什么数据被存下来、存在哪、谁能看到、怎么删掉。 不用法律术语绕弯子，你看完就知道发生了什么。

一、数据存在哪

聊天数据存在站长自己租用的数据库里（Supabase）， 账号由站长独立持有——不是某个公司运营的公共聊天服务， 没有运营商在背后看你的消息。

网页本身托管在 GitHub Pages，它只负责把页面文件送给你， 不接触聊天内容。

换句话说：能看到你消息的人只有两类——你所在的房间的其他成员， 以及有能力直接查数据库的站长。就这两类，没有第三类。

二、存了你的什么

数据为什么需要
昵称别人认出你
登录密码验证是你本人。只存单向哈希，不存明文
注册申请说明站长审核时用
你发的消息聊天本身
你发的图片/视频/语音/文件聊天本身
最后在线时间显示"最近活跃"

不需要手机号、邮箱、真实姓名、通讯录、位置——这些一个都不采集。

关于密码：存的是单向哈希，站长也看不到你的密码原文。 他只能重置，不能"查出来"。
但这也意味着：密码忘了就找不回，只能请站长重置。 所以别用你在别处用过的密码——虽然看不到明文，习惯上仍然值得分开。

三、谁看得到你的消息

场景谁能看到
公屏大厅所有通过审核的成员
群该群成员
私聊只有你们两个
「加密群」不等于端到端加密。 群密码只是进门凭证——挡的是陌生人加入， 不挡有数据库权限的人。站长在数据库层面仍可读到全部消息。 如果你需要真正"站长也看不到"，本站在设计上做不到， 最实际的做法是发完即撤回。

四、你本机存了什么

除了服务端，你的浏览器里也会存一份，目的是离线可用和加快打开：

  • 图片、视频等媒体——缓存，避免每次重新下载
  • 离线时发的消息——排队等你联网后补发，发完清除
  • 登录状态、界面偏好——记住你选的"记住我"、深色模式等

这些都在你自己设备的浏览器里，别人拿不到。 清除浏览器站点数据即可全部删掉（同时会退出登录）。

五、第三方

整站只有两个外部服务：

服务做什么接触聊天内容吗
Supabase存账号、消息、媒体是（它就是数据库本身）
GitHub Pages存放网页文件否

没有统计脚本、没有广告、没有社交插件、没有第三方 Cookie。

六、不做什么

  • 不追踪你在其他网站的行为
  • 不投放广告，也不把数据用于广告
  • 不出售、不交换、不共享给任何第三方
  • 不把聊天内容用于模型训练
  • 不索要通讯录、位置、相机等无关权限 （录音只在你要发语音时申请，图片只在你要发图时读取）

七、怎么删

想删什么怎么做
自己发的某条消息消息操作条 →「删除」
整个会话的记录/clear，或群菜单里清空
本机的缓存浏览器清除站点数据
整个账号找站长，管理面板里删除用户
全站数据站长：管理面板 → 站点 → 重置站点

想带走数据：管理面板 → 站点 → 导出 JSON。 这是你的数据，随时可以拿走。

八、风险说在前面

  • 这是个人项目，没有备份承诺。重要内容请自行导出留存。
  • 站长重置站点会清空全部数据，且不可恢复。
  • 请不要在这里发送身份证号、银行卡、密码等高度敏感信息—— 任何聊天工具都不适合传这些。

九、条款变更

本站功能会迭代，本页内容也会随之调整。 改动会更新在页面上，继续使用即视为知晓最新版本。 有疑问直接问站长——这是个熟人小站，不是客服工单系统。
